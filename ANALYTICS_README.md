# Страница аналитики здоровья

## Описание

Страница аналитики здоровья предоставляет комплексный мониторинг ключевых показателей здоровья пользователя с использованием красивых графиков и интерактивных элементов.

## Функциональность

### 1. Выбор периода анализа
- День
- Неделя (по умолчанию)
- Месяц
- Год

### 2. Основные метрики
- **Уровень риска** - общий показатель здоровья
- **Пульс** - частота сердечных сокращений в ударах в минуту
- **Артериальное давление** - систолическое и диастолическое давление

### 3. Графики
- Динамика уровня риска по дням недели
- Динамика пульса по времени суток
- Динамика артериального давления

### 4. Общий анализ
- Статус здоровья
- Рекомендации на основе трендов
- Период анализа

### API Endpoint
```
GET http://127.0.0.1:8000/analytics/?period=week
```

### Используемые технологии
- **React 19** - основной фреймворк
- **Chart.js** - библиотека для создания графиков
- **react-chartjs-2** - React обертка для Chart.js
- **SCSS** - стилизация с использованием CSS переменных
- **Lucide React** - иконки

## Дизайн

### Цветовая схема
- **Основной цвет**: Ocean Blue (#0092a8)
- **Акцентный цвет**: Dark Blue (#2d40c4)
- **Цвет ошибки**: Red (#f04438)
- **Цвет успеха**: Green (#10b981)
- **Нейтральные цвета**: Серые оттенки

### Стилистика
- Современный минималистичный дизайн
- Плавные анимации и переходы
- Адаптивная верстка для мобильных устройств
- Карточный интерфейс с тенями
- Градиентные заголовки

### Адаптивность
- Desktop: 1200px+ (3 колонки для метрик, 2-3 колонки для графиков)
- Tablet: 768px-1199px (2 колонки для метрик, 1-2 колонки для графиков)
- Mobile: <768px (1 колонка для всех элементов)

## Установка и запуск

1. Убедитесь, что установлены зависимости:
```bash
npm install
```

2. Запустите проект:
```bash
npm run dev
```

3. Откройте страницу аналитики в браузере

## Особенности реализации

### Графики
- Все графики используют Chart.js с настройками для медицинских данных
- Цвета графиков зависят от тренда показателей
- Адаптивные размеры и responsive дизайн
- Интерактивные tooltips с детальной информацией

### Состояния
- Loading состояние при загрузке данных
- Error состояние при ошибках API
- Empty состояние для пустых данных

### Производительность
- React Query для кэширования данных
- Автоматическое обновление каждые 5 минут
- Оптимизированные перерендеры компонентов
