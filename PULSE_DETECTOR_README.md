# Измеритель пульса (Pulse Detector)

## Описание

Компонент `PulseDetector` - это React-компонент для измерения пульса человека через камеру устройства с использованием технологии PPG (Photoplethysmography). Компонент интегрирован в опрос о здоровье и автоматически появляется на вопросе о пульсе.

## Функциональность

### 🔴 Измерение пульса

- **PPG-метод**: Анализ изменений красного канала пикселей с камеры
- **WebRTC**: Использование `navigator.mediaDevices.getUserMedia` для доступа к камере
- **Реальное время**: Непрерывный анализ сигнала и обновление результатов

### 📊 Анализ сигнала

- **Сглаживание**: Применение скользящего среднего для уменьшения шума
- **FFT-анализ**: Быстрое преобразование Фурье для анализа частот
- **Фильтрация**: Ограничение диапазона частот (45-180 BPM)

### 🎯 Точность

- **Диапазон**: 40-200 ударов в минуту
- **Время измерения**: 5 секунд для быстрого результата
- **Стабилизация**: Экспоненциальное сглаживание для стабильного вывода
- **Прогресс**: Визуальный индикатор прогресса измерения

## Технические детали

### Используемые библиотеки

- `fft.js` - для анализа частоты
- `moving-average` - для сглаживания сигнала
- `react-chartjs-2` + `chart.js` - для визуализации

### Алгоритм работы

1. **Захват кадров**: Получение видео с камеры (30 FPS)
2. **ROI-анализ**: Анализ центральной области 80x80 пикселей
3. **Извлечение сигнала**: Вычисление среднего красного канала
4. **Предобработка**: Детрендинг и сглаживание
5. **FFT-анализ**: Преобразование в частотную область
6. **Поиск пика**: Определение доминирующей частоты
7. **Расчет BPM**: Конвертация частоты в удары в минуту

## Использование

### Автоматическая интеграция

Компонент автоматически появляется на вопросе о пульсе в опросе о здоровье. Пользователю достаточно:

1. Нажать кнопку "Начать измерение"
2. Разрешить доступ к камере
3. Приложить палец к камере или держать лицо близко
4. Дождаться результата (10 секунд)

### Ручная интеграция

```tsx
import { PulseDetector } from '@/shared/ui/pulseDetector';

<PulseDetector
  windowSec={10}
  fps={30}
  bpmRange={{ min: 40, max: 200 }}
  showPreview={false}
  onPulseDetected={(pulse) => console.log('Измеренный пульс:', pulse)}
  currentValue={80}
/>;
```

## Параметры

| Параметр          | Тип                          | По умолчанию | Описание                                  |
| ----------------- | ---------------------------- | ------------ | ----------------------------------------- |
| `windowSec`       | `number`                     | `10`         | Продолжительность окна анализа в секундах |
| `fps`             | `number`                     | `30`         | Частота кадров для анализа                |
| `bpmRange`        | `{min: number, max: number}` | `{45, 180}`  | Допустимый диапазон пульса                |
| `showPreview`     | `boolean`                    | `false`      | Показывать превью камеры                  |
| `onPulseDetected` | `(pulse: number) => void`    | -            | Callback при измерении пульса             |
| `currentValue`    | `number`                     | -            | Текущее значение пульса из формы          |

## Советы для точного измерения

### 📱 Мобильные устройства

- Приложите палец к камере
- Включите вспышку для лучшего освещения
- Держите устройство неподвижно

### 💻 Веб-камеры

- Обеспечьте хорошее освещение
- Держите лицо близко к камере
- Избегайте резких движений

### ⚠️ Важные замечания

- **Не медицинский прибор**: Точность зависит от условий измерения
- **Освещение**: Критически важно для качества сигнала
- **Стабильность**: Неподвижность камеры улучшает точность

## Безопасность

- Доступ к камере запрашивается только при нажатии кнопки "Начать измерение"
- Видео поток не сохраняется и не передается
- Анализируются только локальные данные в браузере

## Производительность

- Оптимизированный алгоритм для работы в реальном времени
- Адаптивное качество анализа в зависимости от доступных ресурсов
- Автоматическая очистка ресурсов при остановке измерения

## Совместимость

- **Браузеры**: Chrome, Firefox, Safari, Edge (с поддержкой WebRTC)
- **Устройства**: ПК, планшеты, смартфоны
- **Камеры**: Встроенные и внешние веб-камеры

## Устранение неполадок

### Ошибка "Нет доступа к камере"

- Проверьте разрешения браузера
- Убедитесь, что камера не используется другими приложениями
- Попробуйте обновить страницу

### Неточные результаты

- Улучшите освещение
- Держите камеру неподвижно
- Увеличьте время измерения

### Медленная работа

- Закройте другие вкладки с камерой
- Перезапустите браузер
- Проверьте загрузку процессора
